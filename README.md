# KeurFit – rijbewijskeuringen Nijmegen

Next.js website voor KeurFit. Klaar om als GitHub repository naar Vercel te deployen.

## Lokaal draaien
```bash
npm install
npm run dev
```

## Voor livegang vervangen
- definitieve praktijklocatie + parkeerinformatie
- telefoonnummer en zakelijk e-mailadres
- definitieve tarieven
- KvK- en BIG-informatie waar gewenst
- online boekingslink
- privacyverklaring en klachtenregeling
- domein `keurfit.nl` als een ander domein wordt gekozen

## SEO
De site bevat metadata, lokale zoektermen, FAQ-content, Local/MedicalBusiness structured data, robots.txt en sitemap.xml. Maak na livegang ook een Google Business Profile aan met exact dezelfde bedrijfsnaam, categorie, contactgegevens en locatie/servicegebied.
